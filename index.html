Mac Storage Backup

Mac Storage Backup is a local, single-user tool for verifying the owner’s backup files on Google Drive. It runs on the owner’s Mac and reads selected file metadata and file contents to compare checksums and test restoration.

The application requests the Google Drive read-only permission. It cannot upload, edit, move, share, or delete Drive files using this connection. It is not offered as a public multi-user service.

Google credentials remain in a private local configuration on the owner’s Mac. The tool does not operate an application backend that receives users’ Google Drive contents.
