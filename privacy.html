Privacy policy — Mac Storage Backup

Effective date: 19 October 2026.

Mac Storage Backup is a local tool operated by its owner to verify backup copies. The Google connection requests only `https://www.googleapis.com/auth/drive.readonly`.

Data accessed and purpose

The tool reads metadata of the owner-selected backup files, including names, sizes, identifiers, versions, parent folders and available checksums. It downloads selected contents to calculate a full-file checksum and test restoring each file to a private temporary directory on the owner’s Mac. These operations confirm whether a backup matches the local source.

Storage and retention

OAuth credentials are stored on the owner’s Mac in an owner-only configuration directory. They are not placed in public source code, reports or a hosted application backend. Temporary restored file copies are removed after each verification attempt. Local verification records retain file identifiers, metadata and checksums so the owner can audit the result. The original files and Drive copies remain under the owner’s control.

Sharing and use

The tool does not sell Google user data, serve advertisements, or send downloaded Drive file contents to analytics, advertising or AI training services. Google user data is used only to provide the backup-verification function described above. The tool does not transfer Google Drive file contents to another cloud using this read-only verification connection.

Mac Storage Backup’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Control and revocation

The owner can stop the tool, remove its local verification records and credentials, and revoke Mac Storage Backup access from the Google Account’s third-party connections settings. Revoking access does not delete the original files or cloud backups.

Contact

For this single-user installation, use the developer contact shown on the Google OAuth consent screen.

## Public website hosting

These information pages are hosted on GitHub Pages. GitHub logs visitors’ IP addresses for security purposes. This static site adds no analytics, advertising or tracking scripts and does not receive Google Drive credentials or file contents. See the GitHub Privacy Statement.
